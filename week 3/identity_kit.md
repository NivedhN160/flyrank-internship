## 🔤 1. Typography Selection (Decided Once, Repeated Everywhere)

* **Heading Font:** `Plus Jakarta Sans` (Bold 700 / SemiBold 600)  
  * *Rationale:* Clean, modern geometric sans-serif that conveys technical authority and structural clarity without distracting quirks.
* **Body Font:** `Inter` (Regular 400 / Medium 500)  
  * *Rationale:* Industry-standard legibility on all screen sizes, perfect for technical documentation, case studies, and code annotations.
* **Code / Monospace Font:** `JetBrains Mono` / `Fira Code`  
  * *Rationale:* Crisp monospace font for command-line snippets, SQL queries, and API response JSON.
