## ⏱️ 1. 30-Minute Case Addition Workflow (The 3-Beat Shape)

Whenever a new technical project is completed, follow these 5 steps to index it into the portfolio in under 30 minutes:

1. **Interview AI Workspace (5 mins):** Prompt AI with: *"Interview me using our 3-beat shape (Problem, Decisions, Outcome) for my latest project: {Name}."*
2. **Draft the 3 Beats (10 mins):**
   * **Beat 1: The Problem:** The specific technical bottleneck or business challenge.
   * **Beat 2: What I Did & Decisions:** Key architectural trade-offs, protocols, and data structures.
   * **Beat 3: What Came of It:** Concrete verifiable outcomes (benchmarks, Pytest passes, GitHub repo).
3. **Insert HTML Card (5 mins):** Paste `.case-card` element at the top of `.cases-grid` in `index.html`.
4. **Verify Mobile Viewport (5 mins):** Test $\ge 48\text{px}$ touch targets on mobile screen widths.
5. **Git Push (5 mins):** `git add index.html && git commit && git push` $\rightarrow$ Netlify automatically deploys in $< 30$ seconds.
